# Ignis customer voice in ten minutes

The procedure lives in the packaged guide so every host reads the same text: MCP resource
`fn-ignis://guide/ignis-customer-voice` (prompt `voice_of_customer_audit`; in this repository
`src/ignis/interfaces/mcp/guides/ignis_customer_voice.md`). It relies on the `ignis-tiktok-browser` and
`ignis-threads-browser` skills and the shared `ignis_browser_relay` guide.

Start only for a keyword the person gave and a run they asked for now. The result is attention context,
not a verdict; a decision goes to a mission with a confirmed Market Brief.
