# Query Proof and Complete UAT Contract

## Admission

Browser request must contain the exact assigned keyword in a supported query variable. Response must be successful JSON without GraphQL errors and a supported public post-search envelope. Page navigation and incidental API traffic prove neither. Only the admitted result subtree may be traversed.

For server-rendered Relay results, the successful exact navigation request is necessary but insufficient. The expected preloader must declare BarcelonaSearchResultsQuery with the exact query, and the complete error-free stream result must name that same preloaderID and pass the same public post-envelope validator. Viewer-data, unknown, wrong-query or unassociated stream results cannot authorize observations. Only admitted public data leaves the page evaluation boundary.

Valid empty collection attests execution, not an unmeasured window. Unknown, malformed, error or unrelated envelopes do not authorize records or measured absence. Direct and browser paths share this rule; valid direct empty avoids fallback. Cache signatures cannot bypass proof. Existing non-search consumer behavior and public MCP signatures remain unchanged.
