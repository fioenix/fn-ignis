Where the data comes from

Six connectors, grouped by the runtime each one needs rather than by platform. That grouping is the one that decides what an install can actually do: the unattended worker image ships no browser, so it registers only the connectors that can pull over HTTP, and everything else runs on the operator's own machine with the operator's own session. Threads and Instagram Reels sit in both groups and move between them on their own, depending on whether a Graph API token is configured. What a connector contributes is a second question: only three of the six can discover topics on an untargeted pull. The other three own a feed that belongs to the authenticated account, or a popularity chart, so a public-market pass sends them keywords instead.
