Ingress to dossier

Track 1 discovers topics and fans them out as keyword probes; Track 2 does the same on demand. The unattended radar passes an ingress gate that judges only the script a title is written in, since it accumulates a corpus nobody is watching; Latin script always passes, so English reaches the corpus like Vietnamese does. An agent probe skips that gate entirely and keeps whatever language it found. Relevance is decided at the quality gate, never at ingress.
